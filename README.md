## About

ComicDrama explores how AI can support short drama writing and video production. We are building a connected creative workflow that helps creators organize stories, characters, locations, props, and production tasks in one place.

## AI Drama Studio

AI Drama Studio is an AI-assisted production platform for short dramas. It supports:

- Importing, organizing, and rewriting scripts with AI
- Managing character, location, prop, and character voice assets
- Planning episodes and breaking stories into storyboards
- Generating video prompts and storyboard videos
- Tracking generation tasks, combining clips, and exporting episodes
- Web workflows and a Windows desktop app

## What We Care About

- Making complex AI production workflows easier to understand and manage
- Reusing character and location assets across episodes
- Checking model constraints before generation to help prevent failed tasks
- Improving creative control and visual continuity
