## 소개

ComicDrama는 숏드라마 창작과 영상 제작에 AI를 활용하는 방법을 탐구합니다. 스토리, 캐릭터, 장소, 소품, 제작 작업을 한곳에서 관리할 수 있는 연결된 창작 워크플로를 만들고 있습니다.

## AI Drama Studio

AI Drama Studio는 숏드라마 제작자를 위한 AI 기반 제작 플랫폼입니다. 다음 기능을 제공합니다.

- 대본 가져오기, 정리 및 AI 리라이팅
- 캐릭터, 장소, 소품, 캐릭터 음성 자료 관리
- 에피소드 연출 계획 및 스토리보드 구성
- 영상 프롬프트와 스토리보드 영상 생성
- 생성 작업 추적, 클립 병합, 에피소드 내보내기
- 웹 워크플로와 Windows 데스크톱 앱

## 우리가 중요하게 생각하는 것

- 복잡한 AI 제작 과정을 이해하고 관리하기 쉽게 만들기
- 에피소드 간 캐릭터와 장소 자료 재사용하기
- 생성 전에 모델 제약을 확인해 실패하는 작업 줄이기
- 창작의 주도권과 영상의 일관성 높이기
